Splashed Ink

Browser tools for painting splashed ink on a simulated sheet of paper, and for studying what changes when a machine is your painting partner and the medium pushes back.

  • Splashed InkPour, tilt, pass the paper to a partner. Six friction settings, recorded sessions you can replay.
  • Machine CopyLoad an ink painting and watch the simulator copy it with wet washes, dry-brush strokes and lines of measured width.

Open Splashed Ink on a phone for tilt. The documentation, data formats and the code are in the repository's README and docs folder.
